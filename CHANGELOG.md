## [1.0.0] - 2024-06-02

### Added
- Initial release of Login Tooltips plugin
- Tooltip on the "Remember my login" checkbox on the password page
- Tooltip on the "Secure session (lock to IP)" checkbox
- Multilingual support via MantisBT's language file system
- English language strings
- Spanish language strings
- CSP-compliant tooltip implementation using JSON data blocks
- Automatic cache busting for JavaScript files
- Comprehensive README with bilingual documentation
- MIT License

### Features
- Tooltips appear on hover over login form checkboxes
- Uses Bootstrap's native tooltip functionality
- No external dependencies beyond MantisBT's existing libraries
- Fully compliant with Content Security Policy standards

## [1.0.0] - 2024-06-02

### Añadido
- Lanzamiento inicial del plugin Login Tooltips
- Tooltip en el checkbox "Mantener mi sesión iniciada" en la página de contraseña
- Tooltip en el checkbox "Sesión segura (restringida a la IP)"
- Soporte multilenguaje mediante el sistema de archivos de idioma de MantisBT
- Cadenas de idioma en inglés
- Cadenas de idioma en español
- Implementación de tooltips compatible con CSP usando bloques de datos JSON
- Cache busting automático para archivos JavaScript
- README comprensivo con documentación bilingüe
- Licencia MIT

### Características
- Los tooltips aparecen al pasar el ratón sobre los checkboxes del formulario de login
- Utiliza la funcionalidad nativa de tooltips de Bootstrap
- Sin dependencias externas más allá de las bibliotecas existentes de MantisBT
- Completamente conforme con los estándares de Política de Seguridad de Contenido
